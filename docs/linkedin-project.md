# LinkedIn Project Entry

## Title

Oracle Data Lineage & Impact Analysis Explorer

## Description

Built an Oracle metadata-driven Data Lineage & Impact Analysis Explorer using data dictionary views and PL/SQL pipelined functions.

The project supports upstream and downstream dependency traversal, object and column discovery, cycle-safe graph navigation and an APEX-ready reporting layer. It deliberately distinguishes object dependency analysis from true semantic column-level lineage.

Technologies: Oracle Database, SQL, PL/SQL, Data Dictionary, Data Lineage, Impact Analysis, Oracle APEX.
